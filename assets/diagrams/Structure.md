| Package | Responsibility |
|---|---|
| `screens` | Main menu, gameplay, pause, victory and game over screens. |
| `entities` | Player, enemies, obstacles and collectibles. |
| `world` | World representation, levels and level loading. |
| `systems` | Physics, collisions, input, audio and camera. |
| `ui` | HUD, buttons, menus and interface elements. |
| `data` | Saving, loading and configuration. |
| `progression` | Achievements, unlocks and player progression. |
| `utils` | Constants, asset loading and helper classes. |
